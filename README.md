# Automação de Cadastro de Produtos com Python

## Sobre o projeto

Projeto desenvolvido durante o curso de Python da Hashtag Treinamentos, com o objetivo de automatizar o cadastro de produtos em uma plataforma a partir de dados armazenados em uma planilha CSV.

## Tecnologias utilizadas

- Python
- PyAutoGUI
- Pandas

## Funcionalidades

- Automação da navegação pelo navegador.
- Preenchimento automático de campos.
- Leitura de dados de uma planilha CSV.
- Inserção automatizada de informações de produtos.

## Aprendizados

Este projeto permitiu praticar a manipulação de dados com Pandas e a automação de tarefas com PyAutoGUI.
